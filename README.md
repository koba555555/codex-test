# Codex Test

スマホ対応の「カレンダー式 工程表 + やる事リスト」アプリです。

## できること

- 日付をタップして、その日のやる事を登録
- 月移動で前月/翌月を確認
- 横棒（ガント風）で工程を可視化（開始日〜終了日、進捗%）
- 入力データはブラウザの `localStorage` に保存
- PWA対応（ホーム画面に追加してアプリのように起動）

## これでやる（公開URL化して携帯で開くだけ）

このリポジトリは **GitHub Pages 自動公開** に対応済みです（`.github/workflows/deploy-pages.yml`）。

### 手順

1. GitHub にこのリポジトリを作成して push
2. GitHub の **Settings → Pages → Source** を **GitHub Actions** に設定
3. `main` に push すると自動で公開される
4. 公開URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）を携帯で開く
5. ホーム画面に追加して使う

### ホーム画面に追加

- iPhone（Safari）: 共有 → 「ホーム画面に追加」
- Android（Chrome）: 画面の「このページをアプリ化」ボタン、またはメニューから「ホーム画面に追加」

## ローカル確認

```bash
python3 -m http.server 4173
```

## 注意

- データは**その端末のブラウザ**に保存されます。
- 端末が変わるとデータは自動共有されません。
