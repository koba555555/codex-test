# 工事日誌PWA（Vite + React + TypeScript）

土木施工管理向けに、iPhone現場利用を想定したオフラインファーストの工事日誌アプリです。  
IndexedDB（Dexie）に端末内保存し、写真添付とExcel(.xlsx)出力に対応しています。

## 1) データモデルと画面一覧（短縮版）

### データモデル
- `Diary`（工事日誌本体）
  - 基本: 工事名/施工箇所/日付/天候/気温/作業内容/備考
  - 繰り返し: 人員、重機、材料、温度管理
- `PhotoItem`（写真）
  - 画像Blob（圧縮済みJPEG）
  - 摘要、分類（着手前/施工中/完了/その他）
  - 撮影時刻（ファイルの最終更新時刻ベース）

### 画面
- 一覧（検索 + 新規/保存/複製/削除 + サンプル投入）
- 編集（タブ）
  - 基本
  - 材料/人員
  - 温度
  - 写真
  - 確認&出力

## 2) 実装機能（MVP）
- 工事日誌の新規作成/編集/複製/削除/一覧/検索（日付・工事名）
- 1日複数件保存（ID単位管理）
- 繰り返し入力（人員/重機/材料/温度管理）
- 入力バリデーション（必須項目、人数/数量の数値チェック）
- 写真複数添付、端末内リサイズ圧縮、オフライン閲覧
- Excel(.xlsx)出力（1日誌=1シート）
- PWA化（manifest + service worker自動生成）

## 3) 起動・ビルド・デプロイ

### セットアップ
```bash
npm install
```

### ローカル起動
```bash
npm run dev
```

### ビルド
```bash
npm run build
```

### プレビュー
```bash
npm run preview
```

### デプロイ
`dist/` を静的ホスティング（Cloudflare Pages / Netlify / Vercel / GitHub Pages等）へ配置してください。  
HTTPS配信がPWA動作に必要です。

## iPhoneでホーム画面に追加
1. Safariで公開URLを開く
2. 共有ボタンをタップ
3. 「ホーム画面に追加」を選択
4. 追加後、ホーム画面アイコンから起動

## オフライン確認手順（現場想定）
1. Safariで一度オンライン起動
2. 日誌を新規作成→保存し、写真を2枚以上添付
3. 端末を機内モードにする
4. アプリを再起動し、一覧表示→再編集→再保存できることを確認
5. 再びオンラインに戻し、データが保持されていることを確認

## Excel出力仕様
- ファイル名: `工事名_YYYY-MM-DD.xlsx`
- ワークブック:
  - 1日誌につき1シート（シート名=日付）
- 出力構成:
  1. 基本情報テーブル
  2. 人員テーブル
  3. 重機テーブル
  4. 材料テーブル
  5. 温度管理テーブル（便No, 出荷, 到着, 敷均し, 初期転圧, 二次転圧）
  6. 写真一覧（ファイル名/分類/摘要/撮影時刻）
- 温度管理は必ず表出力（オートフィルタ相当の見やすい行構成）
- 写真はファイル名とメタ情報一覧を出力（容量優先で埋め込み画像は未実装）

## 写真圧縮仕様
- 端末側でJPEGへ変換して保存
- 既定: 最大幅1600px / 品質0.8
- 保存先: IndexedDB（`photos` ストア）

## サンプルデータ
一覧画面の「サンプルデータ投入」ボタンで1件投入できます。

## テスト手順
